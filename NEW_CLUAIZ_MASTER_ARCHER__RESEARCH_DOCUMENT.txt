PART 3: THE MATHEMATICAL SHIFT: 1.58-BIT & MAMBA $O(N)$
"Mamba+BitNet ek sath architecture mein kaise chalte hain?"
════════════════════════════════════════════════════════════════════════════════

Sabse bada confusion: Mamba aur BitNet alag tech nahi hain, ye Model vs Math hain.

MAMBA = The Architecture (The Skeleton)
Mamba decide karta hai data flow. Transformers purane words bar-bar padhte hain ($N^2$).
Mamba past ko ek "Hidden State" mein mila (mix) deta hai.

```python
class MambaCore:
    def __init__(self):
        self.hidden_state = zeros(d_model) # 'Jeevit' state
        
    def process_continuous(self, new_token):
        # A = Forget Filter | B = Remember Filter (Selective Scan)
        delta_A = self.decay_forget(self.hidden_state)
        delta_B = self.absorb_new(new_token)
        
        # O(N) linear update:
        self.hidden_state = delta_A * self.hidden_state + delta_B * new_token
        return self.output_layer(self.hidden_state)
```

BITNET = The Math (The Muscles)
Upar wale `delta_A` ya `delta_B` arrays normal LLMs mein Float16 (16-bit) matrix hote hain.
Humari "BitMamba" approach inhe 1.58-bit (Ternary {-1, 0, 1}) matrices mein quantize kar deti hai.
Matrix multiplication ko addition par switch karte hi GPU Tensor cores seedha 100+ TPS output 
fekte hain.
Formula: `W_q = Round( W / abs(W).mean() )` clipping at -1, 0, 1.

MIMO (Multi-Input Multi-Output):
Mamba-4 concept (MIMO) hume facility deta hai ki OS Event Stream (e.g. CPU_high) 
aur User Chat Stream (e.g. "What to do?") parallel 2 dimensions mein hidden state 
mein feed ho.
