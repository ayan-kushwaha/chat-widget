--------------------------------------
Cluaiz is a "Neural Operating System". It mimics the human brain's 
connectivity to solve the "LLM Context Limit" and "Memory Loss" problems. 
Unlike standard RAG, Cluaiz builds a stateful, learning graph of knowledge.

4. KEY BIOLOGICAL "TRICKS" & LOGIC ⚡
--------------------------------------
🔹 THE 0.6 SIMILARITY LOCK: (focus/manager.py)
   If a new message has >0.6 cosine similarity with the current focus, 
   AI stays in the same FocusSummary node. Prevents "Context Drifting".

🔹 HEBBIAN REINFORCEMENT: (base_neuron.py)
   Whenever a neuron is touched, its priority_score increases by 0.05. 
   "Neurons that fire together, wire together."

🔹 EXPONENTIAL DECAY: (metabolism/janitor.py)
   Weights decay over time (e.g., 5% every 7 days). Only useful or 
   important information stays "Bright" in the brain.

🔹 POLYMORPHIC NEURON SPAWNING: (neurons/factory.py)
   Instead of generic JSON, the builder creates real Python objects with DNA. 
   A ToolNeuron "knows" its API schema; an AgentNeuron "knows" its persona.

🔹 THE HANDOVER GATE: (reflex/handover_gate.py)
   Multi-agent tasks are filtered through a gate. If quality < 0.8, 
   the task is rejected and error_cache is triggered.

8. THE SUBCONSCIOUS ENGINE (LEVEL 4 ARCHITECTURE) 🤖
---------------------------------------------------
Cluaiz uses a highly modular "Digital Atma" inside `src/services/neural` to securely route decisions without relying on slow external LLMs.

📁 /encoder/ : The Universal Translator (Ears)
   - Goal: Translates 100+ raw languages into math vectors instantly.
   - Files: `bge_m3_runner.py` (Converts User Bhasha to Math via BAAI/bge-m3).

📁 /gds/ : The Mathematical Core (Neo4j Deep Graph)
   - Goal: Projects the Neo4j graph into RAM to run algorithms at <100ms speeds without database disk read limits.
   - Files: 
     - `engine.py` : Bridge for 'In-Memory Projected Graphs'.
     - `algorithms.py` : FastRP (Structural Geometry Embeddings) & GraphSAGE real-time memory induction hooks.
     - `centrality.py` : Auto-calculates 'Hebb-Rank' (PageRank) to find mission-critical Business Rules and boost their `priority_score`.

📁 /consensus/ : The Neural Arbiter (The LLM-Free Judge)
   - Goal: Decides the exact execution neural path using pure Math, preventing hallucinations.
   - Files:
     - `arbiter.py` : Evaluates active neurons using the MCES formula: E_i = (α*Centrality + β*Hebbian) * exp(-λ*t) * W_type. (Always picks Business Policy over arbitrary User Moods).
     - `conflict_resolver.py` : Solves Business collisions (e.g. Strict Refund vs Angry User) and outputs a "Mathematical Confidence Score" for the Deep Interface UI.

📁 /subconscious/ : The Proactive Brain (The Atma)
   - Goal: Autonomous action dispatching and background optimization.
   - Files:
     - `router_gguf.py` : Connects to a highly-quantized localized model (BitNet/GGUF) to route JSON decisions in milliseconds.
     - `dreamer.py` : 'Promptless AI'. An event-driven background thread that watches the graph topology during idle hours. If it spots a severe anomaly (CodeChunk crashing a LiveServer goal), it spawns an independent `InsightNeuron` to alert the human boss.

📁 /training/ : Nightly Evolution Pipeline
   - Goal: Ensure the AI gets marginally smarter every single day it works in the company.
   - Files: 
     - `atma_trainer.py` : Runs at 2:00 AM. Extracts the day's successful interactions and conflict logs directly from Neo4j GDS, formats them into an SFT dataset, and fine-tunes the Local GGUF Model's LoRA adapter offline.

9. PILLAR V: THE NEURAL VAULT (ClickHouse) 🗄️
